Sie abonnieren genau die Gruppen, die oben ausgewählt sind: . Änderungen der Gemeinde erscheinen danach automatisch in Ihrem Kalender.

🍏 iPhone / iPad / Mac: Kalender abonnieren 🤖 Android / Google Kalender: abonnieren ⬇️ Einmalig als Datei (.ics) herunterladen

Die Datei (.ics) ist nur eine Momentaufnahme und aktualisiert sich nicht. Besser ist das Abo.

Anleitung iPhone
  1. Auf „iPhone / iPad / Mac: Kalender abonnieren“ tippen.
  2. Bei der Frage „Kalender abonnieren?“ auf Abonnieren tippen.
  3. Farbe wählen, falls gewünscht, dann oben rechts auf Hinzufügen tippen. Fertig.
  4. Für schnelle Aktualisierung: Einstellungen → Apps → Kalender → Accounts → Datenabgleich auf Stündlich stellen.
Anleitung Android / Google Kalender
  1. Auf „Android / Google Kalender: abonnieren“ tippen. Es öffnet sich Google Kalender im Browser. Mit dem Google-Konto anmelden, das auch auf dem Handy eingerichtet ist.
  2. Bei „Kalender hinzufügen?“ auf Hinzufügen tippen.
  3. In der Google Kalender-App: Menü ☰ → Einstellungen → „FBG Eichstätt“ antippen → Synchronisieren einschalten.
  4. Klappt der Knopf nicht: Auf dem Computer calendar.google.com öffnen → links bei „Weitere Kalender“ auf + → Per URL → den kopierten Abo-Link einfügen.

Google aktualisiert abonnierte Kalender von selbst, aber manchmal erst nach einigen Stunden.

Anleitung Samsung Kalender
  1. Zuerst wie bei Android / Google beschrieben abonnieren. Der Samsung Kalender übernimmt Abos über das Google-Konto.
  2. Samsung Kalender öffnen → Menü ☰ → Kalender verwalten (oder Zahnrad → Kalender).
  3. Unter dem Google-Konto „FBG Eichstätt“ einschalten.
  4. Erscheint nichts: Einstellungen des Handys → Konten → Google → Jetzt synchronisieren.

Andere Gruppen gewünscht? Oben die Auswahl ändern und neu abonnieren. Das alte Abo können Sie in der Kalender-App löschen.
